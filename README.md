# maxOS tools releases

Signed and notarized builds of the maxOS tools by SnapNext. This repository holds release assets only: the DMG and `latest.json`. There is no source code here.

Install: download the newest DMG from Releases, open it and drag `maxOS Control` to Applications. Control installs the other tools and shows an Update button when a newer version exists.

Requires macOS 26 on Apple Silicon.
